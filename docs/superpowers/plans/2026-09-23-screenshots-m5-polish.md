# Bufr 3.0 — M5 «Полировка и релиз»: план реализации

> Инлайн-выполнение в `main`; TDD для логики (первый запуск, уведомления, экспорт); окна — сборка и ручной чек-лист.

**Goal:** Довести 3.0 до выпуска:
- в настройках появляется вкладка «Разрешения»;
- при первом запуске 3.0 открывается помощник из трёх шагов: разрешение «Запись экрана», отключение системных сочетаний, папка;
- после обновления появляется подсказка о слетевшем разрешении, а если вставка не работает без Универсального доступа — одно уведомление;
- в `.bufr`-экспорт не попадают локальные пути;
- версия 3.0.0, обновлённый CLAUDE.md, заметки к выпуску и итоговый чек-лист ручной проверки.

**Spec:** разделы 12–14 и строка M5.

## Global Constraints
- Помощник показывается один раз для версии 3.x. Флаг `screenshotSetupVersion` хранится в UserDefaults. Помощник можно открыть снова из настроек скриншотов.
- Подсказка о потере разрешения после обновления — не модальное окно, а уведомление с кнопкой-переходом к помощнику. Показывается при запуске, если `screenCapture == .lostAfterUpdate`.
- Уведомление об Универсальном доступе показывается один раз (`accessibilityHintShown`), при первой вставке, когда `AXIsProcessTrusted() == false`.
- Экспорт досок: у записей очищаются `annotation_path` и `saved_file_path`: это локальные абсолютные пути, в которых есть имя пользователя.
- В M5 делаются и отложенные мелочи прошлых этапов, которые касаются приватности или заметны сразу:
  - временные файлы перетаскивания удаляются при запуске;
  - подсказки на кнопках Quick Access видны, когда Bufr неактивен;
  - после «Сохранить как…» фокус возвращается предыдущему приложению;
  - исправлена гонка при показе уведомлений (toast).

## Review Focus
1. **Экспорт доски со скриншотами:** в `.bufr` нет путей `/Users/<name>/…`. Тест `ExportCompatibilityTests.exportDropsLocalPaths`.
2. **Первый запуск 3.0 и последующие запуски:** помощник показывается ровно один раз, а после «Позже» не надоедает. Тест `LaunchNoticesTests`.
3. **Обновление с потерей разрешения:** подсказка при запуске есть. При `.granted` или `.notRequested` подсказки нет — новичка встречает помощник. Тест `LaunchNoticesTests.permissionLostHintOnlyAfterUpdate`.
4. **Мусор перетаскивания:** старые файлы в `BufrDrag` удаляются при запуске, свежие — сохраняются. Тест `DragFileResolverTests.purgeRemovesOldFiles`.
5. **Строки:** ключи ru/en/uz совпадают, все `L10n`-ключи существуют. Тест уже есть: `LocalizationTests`.

## Задачи
1. Экспорт без локальных путей (тест).
2. `LaunchNotices` — чистая логика «показать помощника», «подсказать про разрешение» (тесты); связка в `AppState`.
3. Вкладка «Разрешения» (`PermissionsSettingsView`) и `SettingsTab.permissions`.
4. Помощник `ScreenshotSetupView` в окне (`AppActivation`), с живыми галочками по шагам.
5. Уведомление об Универсальном доступе при вставке.
6. Отложенные мелочи: очистка `BufrDrag` (тест), подсказки Quick Access, возврат фокуса после «Сохранить как…», гонка уведомлений.
7. Версия 3.0.0 / сборка 30, CLAUDE.md, `docs/release-notes-3.0.md`, итоговый чек-лист ручной проверки.
8. Приёмка: полный `swift test`, release-сборка, запуск, ревью.
