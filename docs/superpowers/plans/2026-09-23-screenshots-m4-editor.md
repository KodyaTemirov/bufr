# Bufr 3.0 — M4 «Редактор аннотаций»: план реализации

> Инлайн-выполнение в `main`; TDD для модели, геометрии, отрисовки (проверка по пикселям) и хранения.
> Холст и окно проверяются сборкой и ручным чек-листом.

**Goal:** Любую картинку из истории можно открыть в редакторе. Инструменты:
- стрелка, линия, прямоугольник, заливка, эллипс, текст, маркер, карандаш, нумерация шагов;
- пикселизация, размытие, прожектор (spotlight), обрезка.

Выбранный объект можно выделять, двигать, менять ручками, удалять, дублировать; работают отмена и повтор. Сохранение правок:
- обновляет картинку карточки и файл в папке;
- оригинал и слои хранятся отдельно, поэтому стрелку можно подвинуть позже;
- можно вернуть оригинал или «сплющить» слои (для приватности после пикселизации).

**Spec:** раздел 10 и решения D8, D9, D15.

## Global Constraints
- Геометрия документа — в пикселях базового изображения, начало сверху слева. Толщина линий и размер шрифта — тоже в пикселях: при создании умножаются на `pointScale`.
- Один `AnnotationRenderer` рисует и холст, и экспорт. Контекст рендера — пиксели с началом сверху слева; картинки рисуются через `drawImageTopLeft`.
- Эффекты (пикселизация и размытие) считаются только по базовым пикселям, поэтому стрелки под ними не размываются. Они рисуются сразу после базы, до векторных объектов.
- Файлы в `images/`: `<u>.png` — плоский результат (его видят карточки, вставка, экспорт); `<u>_orig.png` — оригинал (появляется при первой правке); `<u>.annotations.json` — слои.
- При сохранении правок у записи обновляются `annotation_path`, `hash`, размеры, `created_at = now`, а `ocr_text = NULL` — OCR перезапускается. Файл в папке скриншотов перезаписывается атомарно.
- Окно редактора открывается через `AppActivation.present`. На одну запись — одно окно.
- Маркер — прямоугольный (как «умный маркер» в CleanShot), а не рисуемый от руки: для выделения строк текста это практичнее. Свободное рисование — отдельный инструмент «Карандаш».

## Review Focus
1. **Переворот изображения:** экспорт совпадает с тем, что на холсте. Объект в левом верхнем углу остаётся в левом верхнем углу PNG. Тест `AnnotationRendererTests.topLeftStaysTopLeft`.
2. **Пикселизация необратима в экспорте:** в плоском PNG под пикселизацией нет исходных пикселей — блоки однородные. Тест `AnnotationRendererTests.pixelateProducesUniformBlocks`.
3. **Повторное открытие:** после сохранения и повторного открытия слои те же, их можно двигать, база — оригинал без аннотаций. Тест `AnnotationStoreTests.reopenReturnsLayersOverOriginal`.
4. **«Вернуть оригинал»** восстанавливает байты оригинала, удаляет слои и JSON, файл в папке тоже становится оригиналом. Тест `AnnotationStoreTests.revertRestoresOriginal`.
5. **Обрезка:** размер экспорта равен области обрезки; объекты за её пределами не попадают в результат. Тест `AnnotationRendererTests.cropDefinesOutputSize`.

## Задачи
1. Модель:
   - `RGBAColor`, `AnnotationStyle`, `AnnotationShape`, `Annotation`, `AnnotationDocument` (Codable);
   - операции документа: add, remove, duplicate, `nextCounterNumber`, `topmost(at:)`;
   - `AnnotationTool`;
   - тесты, включая эталонный JSON.
2. Геометрия: границы, попадание, сдвиг, изменение размера (ручки прямоугольников, концы линий), путь стрелки, сглаживание карандаша; тесты.
3. Отрисовка: `AnnotationRenderer`, `EffectRenderer` (Core Image), `CGContext+TopLeft`; тесты по пикселям.
4. Хранение:
   - в `ImageStorage` — файлы слоёв и оригинала, `replaceImage` с пересчётом миниатюры, удаление всех ассетов;
   - в `ClipItemStore` — `applyEdit` и `clearEdit` (узкий UPDATE);
   - `AnnotationStore`: load, commit, revert, flatten;
   - тесты.
5. Холст: `AnnotationCanvasView` (flipped, координаты в пикселях, `NSScrollView` с увеличением), взаимодействие с инструментами, ручки, редактирование текста в `NSTextView`, клавиатура.
6. Окно:
   - `EditorViewModel` (документ, инструмент, стиль, выделение, отмена);
   - `EditorRootView` с панелью инструментов, палитрой и толщиной;
   - `EditorWindowController` и `EditorWindowManager`.
7. Точки входа:
   - карточка («Аннотировать», «Вернуть оригинал», «Сплющить слои»);
   - Quick Access, закреплённый снимок (двойной клик и меню);
   - действие после снимка «Открыть редактор»;
   - строки ru/en/uz.
8. Приёмка, ревью, исправления.
