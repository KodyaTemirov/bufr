# Bufr 3.0 — ручная проверка перед выпуском

Проверять на собранном приложении: `./scripts/build-app.sh debug && open Bufr-Debug.app`.
У отладочной сборки свои настройки и данные, поэтому установленный Bufr она не трогает. На время проверки закройте установленный Bufr — иначе у двух приложений будет общий ⇧⌘V.

## Первый запуск и разрешения
- [ ] Через секунду после запуска открывается «Настройка скриншотов». На шаге 1 «Разрешить…» показывает системный запрос. Галочки обновляются сами.
- [ ] После разрешения и «Перезапустить Bufr» шаг 1 отмечен галочкой.
- [ ] Шаг 2: после отключения сочетаний скриншотов macOS галочка появляется за пару секунд.
- [ ] Повторный запуск помощник не показывает; открыть его можно из «Скриншоты» и «Разрешения».
- [ ] «Разрешения»: статусы «Запись экрана» и «Универсальный доступ», кнопки работают. После возврата из Системных настроек статусы обновляются.
- [ ] Без Универсального доступа первая вставка (Enter в панели) показывает одно уведомление, повторные — нет.

## Захват
- [ ] ⇧⌘4 при включённых сочетаниях macOS: снимает только macOS, Bufr — нет. В настройках хоткеев строка «Занято macOS».
- [ ] После отключения сочетаний macOS ⇧⌘4 открывает оверлей Bufr: лупа, размер в пикселях, ⇧ квадрат, ⌥ от центра, зажатый Space двигает, Esc отменяет.
- [ ] Space до выделения — подсветка окна, клик снимает окно с тенью (PNG с прозрачной тенью).
- [ ] Return без выделения снимает прошлую область.
- [ ] ⇧⌘3 снимает экран под курсором.
- [ ] ⇧⌘5: прошлая область уже выделена, ручки и стрелки работают. «Экран» на панели снимает весь экран, и после этого снова можно выделить новую область.
- [ ] Два дисплея (второй слева или сверху): выделение, подсветка окон, ⇧⌘5 с Return и стрелками на другом дисплее.
- [ ] ⌘Tab во время выделения отменяет его; меню строки меню не попадает в кадр при снимке из меню.
- [ ] Файл в `~/Pictures/Bufr`: имя вида «Снимок экрана … в …», в Инспекторе Preview 144 DPI на Retina.
- [ ] В буфере — PNG, карточка в панели одна (без дубля), на вкладке «Скриншоты» снимок появляется сразу после повторного открытия панели.

## Quick Access и закрепление
- [ ] После снимка в углу миниатюра; наведение останавливает автозакрытие всей стопки; 6+ снимков — «+N».
- [ ] Кнопки: Копировать, Аннотировать, Сохранить как… (после него фокус возвращается), закрепить, Finder, текст, ×. Подсказки видны.
- [ ] Перетаскивание миниатюры и карточки-картинки из панели в Finder, Telegram, Slack, Почту, поле загрузки в браузере.
- [ ] Закреплённый снимок не забирает ввод (можно продолжать печатать). Клик по нему — фокус; прокрутка — прозрачность; стрелки; щипок; L — блокировка; «Разблокировать все» в меню; Esc закрывает.
- [ ] Закреплённый снимок виден на новом скриншоте, окна Bufr — нет.

## Распознавание текста
- [ ] ⇧⌘2 по тексту — «Скопировано символов: N», текст в буфере и в истории; по QR — ссылка; по пустому месту — «Текст не найден».
- [ ] Поиск в панели находит слово с картинки (в том числе со старых картинок после фоновой обработки).
- [ ] «Скопировать текст» в меню карточки, миниатюре и закреплённом снимке.
- [ ] Русский, английский, узбекский (латиница и кириллица) — отметить качество.

## Редактор
- [ ] Все инструменты рисуют; горячие клавиши V A L R F O T H P N X B S C; цвета 1–8; толщина [ ].
- [ ] Выделение, перемещение, ручки, ⌫, ⌘D, стрелки, ⌘Z/⇧⌘Z.
- [ ] Текст: клик — ввод прямо на картинке, Esc или клик мимо — готово; пустой текст исчезает.
- [ ] Пикселизация и размытие; прожектор; обрезка и «Сбросить обрезку».
- [ ] Сохранить или Готово: карточка, миниатюра, файл в папке и закреплённый снимок обновились.
- [ ] Повторное открытие: стрелку можно подвинуть. «Вернуть оригинал» и «Удалить слои» в меню карточки.
- [ ] Закрытие с изменениями спрашивает «Сохранить?».
- [ ] Большой снимок 5K: рисование без заметных задержек.

## Прочее
- [ ] Настройки → «Скриншоты»: папка (выбор, показ, сброс), имя файла с примером, «После снимка», угол и автозакрытие, звук, тень, курсор, Retina 1x, распознавание (прогресс, «Распознать всё заново»).
- [ ] Меню строки меню: все режимы захвата с сочетаниями (если не заняты macOS), «Открыть папку скриншотов», подменю «Закреплённые снимки», предупреждение о разрешении.
- [ ] Экспорт и импорт доски со скриншотом.
- [ ] Тёмная и светлая тема; ru/uz — ничего не обрезается.
